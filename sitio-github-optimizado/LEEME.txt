Casa Juegos Digitales - version optimizada para GitHub Pages

Estructura:
  index.html, catalogo.html, preguntas.html
  assets/bg.jpg, assets/logo.png
  js/catalog.js, js/app.js
  js/steam-about-cache.js  (carga al abrir un juego)

Optimizaciones:
